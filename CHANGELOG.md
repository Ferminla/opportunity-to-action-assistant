# Changelog

## v0.4.0 — public template (2026-11-18)

- Packages the developer-tested V0.4 workflow, with placeholder owner/table settings, stripped credentials and execution data, a storage-creation workflow and optional configuration helper.
- Keeps evidence recovery, deadline normalization, database read-back, priority groups, paginated status and reminder deduplication from the development build.
- Small release-only reminder refinements: align core-required filtering with the progress display, and use singular “1 day away”. These changes received offline smoke tests, not new live n8n integration tests.
- Adds setup, architecture, testing and security documentation and an offline smoke suite.

This is an experimental single-user initial release, not a production SLA or a claim of complete extraction coverage.
